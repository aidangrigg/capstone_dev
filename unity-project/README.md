# Unity project

## Setup

1. Install Unity and import the project. Upon opening the project, Unity should automatically install the correct version & install the required packages.
2. Once the project is open, open the scene "Scenes/SampleScene". The scene also contains an "XRDeviceSimulator" that can be enabled/disabled within the project hierarchy to allow testing without having to connect a VR headset.

## Usage

1. The project can be run alongside the other portions of the project by following the instructions contained in the main README.
2. The scenario can also be controlled manually by selecting "Manual control" on the NeurofeedbackController, and adjusting the sliders to adjust the feedback sources.
